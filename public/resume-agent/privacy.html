# 隐私政策

> 最近更新日期：2026 年 8 月 11 日

## 一键上岸（AI 简历助手）隐私政策（纯前端本地版）

欢迎使用【一键上岸】（以下简称“本产品”）。本产品为**纯前端本地工具**：没有服务器、没有账号系统、不收集你的任何个人信息。请你仔细阅读并充分理解本政策。

### 一、我们不收集信息

1. 本产品没有后端服务器、没有数据库、没有账号注册，因此**不会收集、上传或存储**你的姓名、联系方式、简历内容、IP 地址、操作记录等任何个人信息。
2. 你填写的简历数据只保存在你自己的设备浏览器本地存储（localStorage）中，由浏览器管理，本产品及运营者无法访问。

### 二、信息如何被处理

所有处理（AI 生成、简历诊断、岗位匹配、导出等）均在你自己的设备浏览器内完成，不经过任何服务器。

### 三、数据的存储与删除

1. 数据仅保存在当前浏览器（localStorage）。
2. 你可以随时点击页面右上角「重置」清空全部数据；清除浏览器网站数据也会删除全部简历。
3. 换设备或换浏览器不会自动迁移数据——如需迁移，请使用「导出备份 JSON」后在新设备「导入备份」。

### 四、第三方

本产品默认不调用任何第三方服务。如你自行开启真实大模型接入（需自备 API 代理服务），相关数据将按你配置的服务处理，与本产品默认行为无关。

### 五、未成年人

本产品面向求职者。若你未满 14 周岁，请在监护人指导下使用。

### 六、政策的更新

本政策可能适时更新。更新后的政策自发布之日起生效。
