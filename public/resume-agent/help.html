使用说明

一键上岸（AI 简历助手）· 纯前端本地版 · 无需登录，数据只保存在本机

一、如何打开

  • 最简单：双击 index.html（推荐用最新版 Chrome / Edge 打开）。
  • 本地服务：在 ai-resume-agent 目录执行 python -m http.server 8765 --directory .，然后访问 http://127.0.0.1:8765。

二、六步使用流程

  • 1 对话引导：像聊天一样回答 AI 的问题，它会帮你挖掘课程设计、社团活动、实习里的亮点；不想对话可以直接「跳过」或「先看示例」。
  • 2 智能生成：在 A4 预览纸上直接编辑；右侧 AI 建议面板可一键采纳「表述优化 / 量化补充」。
  • 3 模板排版：11 套模板 + 主题色 + 字号 + 行距 + 照片，实时预览。
  • 4 诊断优化：六维评分 + 雷达图 + 问题清单，一键修复；另有「文字与格式体检」检查错别字、日期格式、口语化表达等。
  • 5 岗位匹配：粘贴 JD 自动分析匹配度与关键词差距（截图识别需配置 OCR，可手动粘贴文本）。
  • 6 导出投递：PDF（打印）、Word（真实 .docx）、分享网页（单文件 HTML）、ATS 纯文本（网申直接粘贴）、JSON 备份；多版本管理与投递台账。

三、数据与隐私

  • 所有数据只保存在当前浏览器本地（localStorage），不上传任何服务器，不需要注册登录。
  • 清除浏览器网站数据 = 永久删除简历，请定期在「导出投递 → 数据备份 → 导出备份」保存 JSON。
  • 换电脑 / 换浏览器：先在旧设备「导出备份」，再在新设备「导入备份」即可迁移。

四、如何分享给别人

  • 分享整个工具：把 ai-resume-agent 文件夹压缩打包发给对方，解压后双击 index.html 即可使用，无需安装任何软件。
  • 分享单份简历：用「分享简历网页」导出单文件 HTML，或导出 PDF / Word 发给招聘方。

五、常见问题

  • 打开是空白页？ 请使用最新版 Chrome / Edge，并确认未禁用 localStorage。
  • AI 为什么没有调用大模型？ 纯前端版默认使用内置 AI 引擎，离线也能「一键生成」；如需真实大模型，需自备 API 代理并在代码中开启。
  • 换设备数据没了？ 数据在浏览器本地，请用「导出备份 / 导入备份」迁移。
