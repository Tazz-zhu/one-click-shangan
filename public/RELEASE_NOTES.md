# 一键上岸 更新日志

## v1.0.0 (2026-08-14)

### 🎯 首个版本：AI 求职 Agent

一键上岸 = 简历助手 + 面试助手，一站式完成「写简历 → 押题 → 模拟面试 → 拿 Offer」。

- 📄 **简历助手**：AI 对话引导写简历、模板排版、六维诊断、岗位匹配、PDF / Word / HTML / ATS 导出（纯前端本地版）
- 🔗 **简历 → 面试 一键同步**：简历 ATS 文本与 JD 自动带入「分析 & 押题」，无需重复粘贴
- 🔍 **分析 & 押题**：JD 解析 → 简历解析 → 差距分析 → 五类题型 AI 押题（支持 Boss直聘 / 51job 链接扒取、快速模式）
- 💪 **单题练习**：五维深度评分、逐句点评、AI 标准答案、话术库
- 🎤 **全真模拟面试**：多阶段追问、五维雷达图 + 逐题点评报告
- 📡 **面经采集**：小红书面经搜索 + OCR + LLM 结构化
- 👥 **群面模拟 / 专项训练 / 公司调研 / 错题集 / 备考方案 / 面试复盘**
- 🛡️ **数据本地化**：账号、面试记录、简历全部保存在本机，不上传云端
